# ПДР Тренер

Офлайн Android-застосунок для того, щоб вивчити **всі** питання теоретичного іспиту ТСЦ МВС для категорій **B** і **C** — з поясненнями та інтервальним повторенням.

- 1960 офіційних питань (1697 спільних + 65 лише для B + 198 лише для C), 1108 ілюстрацій.
- До кожного питання — коротке пояснення, підказка для запам'ятовування і посилання на пункти ПДР (згенеровано ШІ з перевіркою за текстом ПДР; сумнівні місця позначено ⚠️).
- Повний текст ПДР (редакція з zakon.rada.gov.ua) всередині застосунку; посилання з пояснень відкривають потрібний пункт.

## Як воно вчить

**FSRS** — сучасний алгоритм інтервального повторення (той самий, що в Anki). Для кожного питання він веде «стабільність пам'яті» і показує питання саме тоді, коли ймовірність його пригадати падає до цільового рівня (за замовчуванням 95%).

- Щодня: усі повторення + N нових (налаштовується).
- Неправильна відповідь → питання повертається в цій же сесії через кілька карток, доки не відповісте правильно, і знову завтра.
- Правильно, але навмання → «Вгадав» (рахується як помилка).
- **Шанс скласти іспит**: з поточної пам'яті по всіх питаннях рахується ймовірність зробити ≤ 2 помилки на 20 випадкових питаннях.
- **Дата іспиту** → скільки нових на день треба, щоб встигнути, і прогноз на день іспиту.
- Режими: пробний іспит (20 питань / 20 хв), розділи, «найслабші», «складні» (часті помилки), пошук.

## Структура

```
scripts/scrape.py              # збирає питання B/C і картинки (pdrtest.com, дзеркало офіційної бази ГСЦ МВС)
scripts/merge_explanations.py  # зливає пакети пояснень у data/explanations.json з перевіркою (одноразово)
scripts/apply_fixes.py         # накладає виправлення після перевірки; data/explanations.json — джерело правди
scripts/build_assets.py        # складає web/ + data/ в android/app/src/main/assets/www
data/questions.json            # питання, правильні відповіді, розділи
data/explanations.json         # пояснення, підказки, посилання на ПДР
data/pdr_rules.json|txt        # текст ПДР за розділами
data/img/                      # ілюстрації (webp)
web/                           # застосунок (HTML/CSS/JS, без залежностей)
android/                       # WebView-обгортка (Java, без AndroidX)
tests/fsrs.test.js             # тести планувальника
```

## Збірка APK

Потрібні JDK 17+ та Android SDK (platform 35, build-tools 35).

```bash
python3 scripts/build_assets.py
cd android && ./gradlew assembleRelease
# -> android/app/build/outputs/apk/release/app-release.apk
```

Ключ підпису лежить у `android/keystore/` навмисно: кожна нова збірка ставиться поверх старої без втрати прогресу. Прогрес зберігається у WebView localStorage; є експорт/імпорт у налаштуваннях.

Тести: `node --test tests/fsrs.test.js`.
